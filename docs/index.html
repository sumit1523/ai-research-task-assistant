What the app does

Instead of being a generic chat box, the assistant follows a visible, stateful workflow and keeps useful work local.

1

Bring trusted context

Paste notes, add public webpage URLs, or upload a PDF, text, or Markdown file.

2

Get a grounded answer

The assistant prepares source text, produces a concise summary, and labels the inputs it used.

3

Take action

Receive timed tasks, check them off, see progress, and ask the agent to revise the plan.

Where each AI concept is used

LangChain: the AI building blocks

ChatPromptTemplate defines the research and revision prompts. RecursiveCharacterTextSplitter breaks large source text into manageable chunks. ChatGroq calls the hosted Qwen model and returns the summary and timed plan.

LangGraph: the agent workflow

The graph keeps request state and decides the next step. A short question routes to clarify; a normal request routes through prepare_context and research_and_plan; feedback routes to revise.

LangSmith: observability and evaluation

When LANGSMITH_TRACING=true and a valid key are configured, LangSmith records every graph run, model call, prompt, latency, output, and error. The included evaluation dataset tests whether expected concepts appear in generated results.

Human-in-the-loop agent

The user is always in control. They can adjust the plan with a request such as “I have only 30 minutes a day.” The graph enters the revision path and produces a new, more realistic plan.

The AI agent in this project

The agent is not just a single chat prompt. It uses state, chooses a workflow path, works with source context, and changes its plan after human feedback.

1

It decides the next step

The LangGraph decide node inspects the current state. Very short or vague questions go to a clarification response; normal questions go to research; feedback on an existing plan goes to revision.

2

It uses tools and context

The agent works with loaded webpage text, uploaded PDFs, notes, a text splitter, prompt templates, and the hosted Qwen model. These tools help it create a grounded answer instead of answering from a blank chat window.

3

It keeps a useful state

State holds the question, prepared context, summary, task plan, and revision request. This lets the agent revise the same plan rather than starting again when the user says their available time has changed.

Source ingestion and grounding

Web pages

The app fetches public HTTP(S) links, removes navigation, scripts, and styling noise, then retains readable text. It rejects local URLs.

Uploaded files

PDF, TXT, and Markdown files are read in memory; they are not copied to a cloud storage bucket. AES-PDF support is included, and password-protected files return a friendly message.

Context preparation

Source text is split into overlapping chunks before reaching the model. This is a lightweight RAG-style foundation that keeps the prompt focused and is easy to understand.

Grounded output

The research prompt asks the model to rely on provided context for factual claims and to label no-source answers as general guidance.

Data, privacy, and safety

Local history

Research sessions and task completion live in the local research_tasks.db SQLite database. The file is excluded from Git.

Secret protection

API keys belong in .env. That file is ignored by Git and never included in the repository or this public site.

Explicit user actions

The agent recommends and revises; it does not send emails, make purchases, or alter external accounts.

Transparent errors

URL, file, PDF encryption, and cloud-model failures are presented separately so users see an actionable explanation rather than a vague failure.

How the project is tested

Evaluation tests: evaluate.py sends stable example questions through the agent and checks that a summary, task plan, and expected source concept are present.

Workflow tests: the app has been exercised through initial research, the LangGraph revision branch, persistent task completion, PDF handling, and Streamlit UI tests.

LangSmith test: with a valid LangSmith API key, send one request and inspect the ai-research-task-assistant project to view the nested graph and model trace.
